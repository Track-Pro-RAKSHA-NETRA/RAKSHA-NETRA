# RAKSHA-NETRA

### Edge-AI × Multimodal Sensing × Cybersecurity

> A proposed rugged, handheld platform for rapid presumptive trace screening in railway security environments.

---

## 🚨 Problem

Railway security requires fast, portable and reliable field-screening support, especially where connectivity may be limited.

---

## 💡 Our Solution

**RAKSHA-NETRA** combines:

- 🔬 Multimodal chemical sensing
- 🤖 Edge-AI inference
- 🔐 Cryptographically protected event logs
- 📡 Offline-first operation
- 📊 Device-to-dashboard reporting

### Core Flow

**COLLECT → ANALYZE → FUSE → CLASSIFY → ALERT → SECURE → REPORT**

---

## ⚙️ Technology Stack

| Layer | Technology |
|---|---|
| MCU | STM32 |
| Edge Computing | Raspberry Pi 5 |
| AI | TensorFlow Lite |
| VOC | BME688 + SGP40 |
| Electrochemical | SPCE + AD5940 |
| Optical | TCS34725 + Camera |
| Security | AES-256 + SHA-256 + Hash Chain |
| Connectivity | Wi-Fi + 4G/LTE |
| Design | EasyEDA + Figma |

---

## 🔐 Security & Resilience

**AES-256** → Confidentiality  
**SHA-256** → Integrity  
**Hash Chain** → Event traceability  
**Device ID + Timestamp + GPS** → Provenance  
**Offline Storage** → Connectivity resilience
